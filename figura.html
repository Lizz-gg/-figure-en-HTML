¿Qué es HTML semántico?

HTML semántico es el uso de etiqueta HTML que describen claramente el propósito del contenido, como <article>, < nav> o <footer> en lugar de solo <div>

¿Por qué es importante la accesiilidad?

La accesibilidad garantiza que todas las personas, incluyendo aquellas con discapacidades visuales, auditivas o motoras, pueden navegar y uar nuestros sitios web. usar etiquetas semánticas y atributos ARIA ayuda a los lectores de pantalla a interpretar corecctamente el contenido
